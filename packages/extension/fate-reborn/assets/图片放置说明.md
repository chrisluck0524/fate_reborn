# 宿命 Reborn 图片放置说明

把图片放进本目录的 `heroes` 或 `cards` 文件夹。请统一使用 `.jpg`，英雄图推荐竖版 `720 × 960`，卡牌图推荐竖版 `600 × 900`。

## 英雄牌

文件名必须和英雄 ID 一样，例如亚巴顿使用：

`heroes/fate_abaddon.jpg`

全部英雄 ID：

`fate_abaddon`、`fate_skeleton_king`、`fate_bristleback`、`fate_huskar`、`fate_omniknight`、`fate_axe`、`fate_guardian_knight`、`fate_lina`、`fate_necrophos`、`fate_jakiro`、`fate_crystal_maiden`、`fate_lich`、`fate_dazzle`、`fate_ogre_magi`、`fate_keeper_of_the_light`、`fate_techies`、`fate_enchantress`、`fate_medusa`、`fate_razor`、`fate_juggernaut`、`fate_vengeful_spirit`、`fate_bloodseeker`、`fate_troll_warlord`、`fate_sniper`、`fate_nyx_assassin`、`fate_anti_mage`、`fate_chen_yunsheng`。

## 卡牌

卡牌图建议以牌 ID 命名，例如：

`cards/fate_fanatical.jpg`、`cards/fate_eye_of_skadi.jpg`、`cards/fate_divine_strength.jpg`。

完整牌 ID 定义在 `src/cards.js`、`src/equipment.js` 和 `src/heroes-strength.js` 中。基本牌使用 `sha`、`shan`、`tao`、`wuxie` 四个 ID。

英雄图片已按上述命名自动接入。卡牌图片需要我在牌面代码中启用对应图片路径，以避免尚未提供图片时出现空白牌面。你把图片放好后告诉我“已放图”，我会负责检查文件名、接入牌面并重新打包。
