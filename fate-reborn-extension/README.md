# 宿命 Reborn 无名杀扩展

这是《宿命》的无名杀模式实现。Godot 原型继续作为规则验证器，本目录负责正式的无名杀适配。

## 行动与结算顺序

所有涉及角色顺序的行动、施法、驱散、技能触发及多目标效果，一律从相应起点按逆时针结算。不得直接遍历 `game.players` 或使用引擎的顺时针默认排序；扩展使用 `actionOrder` / `orderedTargets`。路径决定目标集合时，实际结算仍按逆时针执行。

## 当前完成

- 5—8 人标准局；5 人固定为 `2天辉 + 2夜魇 + 1中立`，8 人使用 `3天辉 + 3夜魇 + 2中立`。
- 标准局由玩家从完整英雄池选将；每名 AI 从 3 名随机候选英雄中自动选 1 名。
- 每名玩家知道自己与固定座位下家的身份。
- 27 名英雄的力量、智力、敏捷分类，以及血量和固定手牌上限。
- 27 名英雄的力量、智力、敏捷专属技能均已接入。主动技能的后续效果通过虚拟魔法牌结算，可进入驱散响应链；自伤与弃牌费用在响应前支付。
- 受实际伤害获得怒气，上限为 3。
- 53 张基本牌：12 张普通攻击、10 张混乱攻击、8 张火焰攻击、15 张闪避、8 张治疗药膏；攻击响应与濒死救援复用无名杀的成熟流程。
- 33 张魔法牌全部进入牌堆：狂热、误导、查克拉、野性之斧、驱散、缴械、月神之箭、能量转移、贪婪、海妖之歌。魔法牌使用无名杀的无懈响应链，因此驱散也可再次被驱散。
- 缴械、月神之箭、能量转移、贪婪和海妖之歌已支持在驱散响应前支付1点怒气进行强化，效果被驱散后怒气不退还。
- 9 张 S 技牌：神之力量、蝮蛇突袭、时间静止、灵魂隔断、神灭斩；按牌面消耗 2 或 3 点怒气，且不可被驱散。
- 17 张装备牌：12 件武器与 5 件防具均已进入牌堆，并接入攻击距离、转化用牌、额外摸牌、伤害与怒气修正、装备限制、判定防护和补刀归属等效果。
- 每回合开始前触发 `fateCastPhase`，作为施法技能的统一入口。
- 回合推进和宿命结算按逆时针座次处理；每名中立角色记录固定座位下家。
- 8 张宿命及其胜负判定；反噬的傀儡和 Roshan 已进入标准随机池。Roshan 的公开身份结算骨架已接入，首位可见的 Roshan 会在开局结算时触发特殊结算，其他公开身份入口仍需实机验证。
- 死亡来源可选择摸两张牌，或从存活角色中选择一名查看身份。

当前可用牌堆共 112 张。海妖之歌已阻止其他角色用卡牌指定状态中的角色；施法阶段产生的竭心光环、冰霜禁制和薄葬会先进入待处理状态区，并在状态判定阶段生效，再由目标回合结束时清理。状态区的完整卡牌可视化仍待接入。

## 验证

自动测试验证的是规则数据、宿命判定和少量纯函数，不等同于完整客户端验收。英雄技能、施法阶段、驱散链、死亡顺序和 UI 操作仍需按 `英雄技能核查.md` 的试玩重点逐项验证。

在本目录执行：

```bash
node --test tests/*.test.mjs
```

在无名杀仓库根目录安装依赖后执行：

```bash
pnpm --filter @noname-extension/fate-reborn build
```

构建产物会写入 `apps/core/extension/fate-reborn`。启用扩展后，开始菜单会出现“宿命”模式。
